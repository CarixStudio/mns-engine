# MNS Engine

MNS Engine is a modern algorithmic trading framework built for MetaTrader 5 (MQL5).

## Directory Structure

- **.github/workflows**: CI/CD automation pipelines.
- **docs/**: Project documentation (PRD, Architecture, Roadmap, Decisions).
- **src/**: Source code containing Expert Advisors, Indicators, Libraries, and Scripts.
- **tests/**: Automated unit and integration tests.
- **tools/**: Development, testing, and helper tools.
