# Module 007 — Liquidity Engine API

## 1. Class Interface Contract

The `CLiquidityEngine` class is defined as follows:

```mql5
//+------------------------------------------------------------------+
//| CLiquidityEngine Class                                           |
//+------------------------------------------------------------------+
class CLiquidityEngine
{
private:
    bool                m_isInitialized;            ///< Lifecycle initialization watermark.
    SLiquidityPool      m_pools[128];               ///< Fixed-size array of tracked liquidity pools.
    int                 m_poolsCount;               ///< Total number of tracked pools.
    int                 m_lastProcessedSwingCount;  ///< Swing count watermark.
    int                 m_gmtOffset;                ///< Broker GMT offset.

    // Private helper methods
    void                DetectDailyWeeklyLevels(const double &high[], const double &low[], const datetime &time[], int ratesTotal);
    void                DetectEqualPivots(const CSwingDetector &swingDetector, double currentAtr);
    void                CheckSweepsAndBreakouts(const double &high[], const double &low[], const double &close[], const datetime &time[], double currentAtr, double minBreakDistance);
    void                RankPools(const CDeliveryStructureEngine &deliveryEngine);
    int                 FindPoolIndexByLevel(double level, ELiquidityType type) const;

public:
    // Lifecycle
    CLiquidityEngine();
    ~CLiquidityEngine();

    /// @brief Initializes engine variables and sets broker GMT offset.
    /// @param gmtOffset GMT offset in hours.
    /// @return True on success.
    bool                Initialize(int gmtOffset = 0);

    /// @brief Resets the engine state.
    void                Reset();

    /// @brief Evaluates price bars and swings to find and update liquidity pools.
    /// @param swingDetector Confirmed swings database.
    /// @param deliveryEngine Active delivery structure engine.
    /// @param high price array
    /// @param low price array
    /// @param close price array
    /// @param open price array
    /// @param time array
    /// @param ratesTotal total elements in price arrays
    /// @param prevCalculated processed bars count
    /// @param currentAtr ATR value
    /// @param minBreakDistance minimum breakout threshold
    /// @return True if state changed.
    bool                Update(const CSwingDetector &swingDetector,
                               const CDeliveryStructureEngine &deliveryEngine,
                               const double &high[],
                               const double &low[],
                               const double &close[],
                               const double &open[],
                               const datetime &time[],
                               int ratesTotal,
                               int prevCalculated,
                               double currentAtr,
                               double minBreakDistance);

    // Query Methods
    int                 GetPoolsCount() const { return m_poolsCount; }
    
    /// @brief Gets a liquidity pool by index.
    /// @param index Pool index.
    /// @param outPool Structure output by reference.
    /// @return True if index is valid.
    bool                GetPool(int index, SLiquidityPool &outPool) const;

    /// @brief Returns the nearest active buy-side liquidity level.
    /// @param currentPrice Current market close.
    /// @return Price level, or DBL_MAX if none active.
    double              GetNearestBSL(double currentPrice) const;

    /// @brief Returns the nearest active sell-side liquidity level.
    /// @param currentPrice Current market close.
    /// @return Price level, or 0.0 if none active.
    double              GetNearestSSL(double currentPrice) const;
};
```
