## Class Name: `CBreakDetector`

Header File: `Include/MNS/CBreakDetector.mqh`

---

## Public Interface

### Lifecycle
- `bool Initialize()`
  Initializes the class member variables, resizes history arrays to maximum capacity (`MNS_MAX_STRUCTURE_BREAKS`), and marks as initialized.
- `void Reset()`
  Resizes break histories to 0, resets cached latest breaks, and resets processed counters.

### Update Cycle
- `bool Update(const CSwingDetector &swingDetector, const CStructureEngine &structureEngine, const double &high[], const double &low[], const double &close[], const double &open[], const datetime &time[], int ratesTotal, int prevCalculated, double currentAtr)`
  Processes closed bars to detect new structural breaks (BOS, iBOS, CHoCH). Returns true if a new break is confirmed.

### State & Getters
- `int GetBreakCount() const`
  Returns the total number of breaks stored.
- `SStructureBreak GetBreak(int index) const`
  Returns the break at the given zero-based chronological storage index. Returns an empty break if index is out of range.
- `SStructureBreak GetLatestBOS() const`
  Returns the most recent confirmed BOS structure break.
- `SStructureBreak GetLatestIBOS() const`
  Returns the most recent confirmed iBOS structure break.
- `SStructureBreak GetLatestCHOCH() const`
  Returns the most recent confirmed CHoCH structure break.
- `bool HasBullishBOS() const`
  Returns true if the latest external BOS was bullish (broken high).
- `bool HasBearishBOS() const`
  Returns true if the latest external BOS was bearish (broken low).
- `bool HasBullishIBOS() const`
  Returns true if the latest internal BOS was bullish (broken high).
- `bool HasBearishIBOS() const`
  Returns true if the latest internal BOS was bearish (broken low).
- `bool HasBullishCHOCH() const`
  Returns true if the latest CHoCH was bullish (wicked above bearish trend's high).
- `bool HasBearishCHOCH() const`
  Returns true if the latest CHoCH was bearish (wicked below bullish trend's low).

---

## Private Members

- `bool m_isInitialized`
  Flag to track initialization.
- `SStructureBreak m_breaks[]`
  Chronological array storing all confirmed breaks.
- `int m_breakCount`
  Count of breaks in `m_breaks`.
- `int m_lastProcessedRatesTotal`
  Tracks ratesTotal to ensure we only scan new candles incrementally.
- `SStructureBreak m_latestBOS`
  Cached copy of the latest BOS.
- `SStructureBreak m_latestIBOS`
  Cached copy of the latest iBOS.
- `SStructureBreak m_latestCHOCH`
  Cached copy of the latest CHoCH.
- `SStructureBreak m_emptyBreak`
  Sentinel returned for out-of-bounds queries.

### Private Helpers
- `bool IsBreakAlreadyRecorded(datetime swingTime, EStructureBreak type) const`
  Returns true if a break of the specified type has already been logged for the swing point at `swingTime`.
- `void RecordBreak(int barIndex, double price, datetime time, EStructureBreak breakType, EStrength strength, const SSwingPoint &brokenSwing, double displacement, double atrMultiple)`
  Builds, caches, and appends a confirmed `SStructureBreak` object.
- `bool EvaluateBarForBreaks(int index, const CSwingDetector &swingDetector, const CStructureEngine &structureEngine, const double &high[], const double &low[], const double &close[], const double &open[], const datetime &time[], int ratesTotal, double currentAtr)`
  Evaluates a single bar index for breaks.
