Version: 1.0
Status: Approved

## Class Name: `COrderFlowEngine`

Header File: `Include/MNS/COrderFlowEngine.mqh`

---

## Public Interface

### Lifecycle
- `bool Initialize()`
  Initializes the class member variables, resets state, and marks the engine as initialized. Returns true on success.
- `void Reset()`
  Resets the order flow state to `ORDER_FLOW_NEUTRAL` and resets all processed break counters.

### Update Cycle
- `bool Update(const CSwingDetector &swingDetector, const CStructureEngine &structureEngine, const CBreakDetector &breakDetector, const double &high[], const double &low[], const double &close[], const double &open[], const datetime &time[], int ratesTotal, int prevCalculated, double currentAtr)`
  Evaluates new structural breaks and updates the active order flow direction, state, and confidence scores. Returns true if the order flow state was modified during the update.

### State & Getters
- `SOrderFlowState GetState() const`
  Returns the active `SOrderFlowState` structure by value.
- `EOrderFlowDirection GetDirection() const`
  Returns the active order flow direction (`ORDER_FLOW_DIR_BULLISH`, `ORDER_FLOW_DIR_BEARISH`, `ORDER_FLOW_DIR_NEUTRAL`).
- `EOrderFlowState GetGranularState() const`
  Returns the granular order flow state (including transitions).
- `double GetConfidenceScore() const`
  Returns the active order flow confidence score (0 to 100).
- `bool IsBullish() const`
  Returns true if order flow is bullish.
- `bool IsBearish() const`
  Returns true if order flow is bearish.
- `bool IsTransition() const`
  Returns true if order flow is in a transition state.
- `bool IsNeutral() const`
  Returns true if order flow is neutral.
- `EAlignmentState GetAlignmentWith(ETrend trend) const`
  Compares order flow direction against the structure trend and returns `ALIGN_ALIGNED`, `ALIGN_NEUTRAL`, or `ALIGN_CONFLICT`.

---

## Private Members

- `bool m_isInitialized`
  Flag to track class initialization status.
- `SOrderFlowState m_state`
  The current Order Flow state object.
- `int m_lastProcessedBreakCount`
  Tracks the number of breaks processed in `CBreakDetector` to scan incrementally.

### Private Helpers
- `void UpdateStrengthsAndConfidence(const CStructureEngine &structureEngine, const CBreakDetector &breakDetector, const double &high[], const double &low[], const double &close[], const double &open[], const datetime &time[], int ratesTotal, double currentAtr)`
  Calculates and updates confidence score and directional strength metrics based on recent market activity.
- `bool FindLatestSwingBefore(const CSwingDetector &detector, datetime limitTime, ESwingType type, SSwingPoint &outSwing) const`
  Scans swing history backwards to find the latest confirmed swing of the specified type occurring before `limitTime`. Returns true if found.

## Dependencies

- `MNSTypes.mqh`
  For enums (`ETrend`, `ESwingType`, `EStructureBreak`, `EStrength`), structures (`SSwingPoint`, `SStructureBreak`), and core constants.
- `CSwingDetector.mqh`
  To inspect confirmed swing points.
- `CStructureEngine.mqh`
  To check the trend/phase and internal swing alignments.
- `CBreakDetector.mqh`
  To process structural breaks and identify displacement-aware BOS/CHoCH events.
