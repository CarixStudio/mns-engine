# Module Specifications

Detailed specifications for every component/module within the MNS Engine.

## Modules

### 1. Risk Manager
- **File**: `src/Include/MNS/RiskManager.mqh`
- **Purpose**: Controls maximum drawdown, position sizing, and daily loss limits.

### 2. Execution Engine
- **File**: `src/Include/MNS/ExecutionEngine.mqh`
- **Purpose**: Low-latency trade execution, order tracking, and slippage management.

### 3. Signal Evaluator
- **File**: `src/Include/MNS/SignalEvaluator.mqh`
- **Purpose**: Combines multiple indicator inputs to output trade signals.
