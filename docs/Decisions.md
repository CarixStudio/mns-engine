# Architecture Decision Records (ADR)

## ADR 1: Repository Structure
- **Status**: Approved
- **Context**: Standardizing MetaTrader 5 MQL5 workspace.
- **Decision**: Organize files into distinct docs, src (Include, Experts, Indicators, Libraries, Scripts), tests, and tools directories.
- **Consequences**: Easier CI/CD configuration, clear division of responsibilities, and isolated dependencies.
