# MQL5 Coding Standards

This document defines the coding conventions, naming standards, and architectural guidelines for the MNS Engine.

## Naming Conventions
- **Classes**: PascalCase starting with `C` (e.g., `CAccountManager`).
- **Functions/Methods**: PascalCase (e.g., `GetBalance`).
- **Variables**: camelCase (e.g., `accountBalance`).
- **Constants/Macros**: UPPER_CASE (e.g., `MAX_RETRY_LIMIT`).
- **Files**: PascalCase or matching class names.

## Formatting
- Use 4 spaces for indentation (no tabs).
- Open curly braces `{` on a new line or same line consistently (prefer new line for function definitions).
