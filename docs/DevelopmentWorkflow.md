# Development Workflow

This document outlines the collaboration model between human developers and AI assistants to build, test, review, and commit code for the MNS Engine.

## Branching Strategy
- **main**: Production-ready code.
- **feature/* / bugfix/* / chore/**: Active development branches.

## Review and Commit Workflow
1. Create a feature branch.
2. Implement and locally verify changes in MT5/MQL5.
3. Keep commits atomic and descriptive.
4. Open a Pull Request and run verification tests.
